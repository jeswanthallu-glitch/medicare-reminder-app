# 💊 MediCare Reminder — Medication Reminder App

## 📌 Project Overview

MediCare Reminder is an application designed to help elderly people remember to take their medicines on time. It aims to make medication management easier for patients and help caregivers stay informed about missed doses.

## 🎯 Problem Statement

Elderly people may forget medication schedules, dosage instructions, or whether they have taken their medicines. Caregivers may also find it difficult to monitor medication adherence when they are not physically present.

## ✨ Key Features

- Patient and caregiver accounts
- Medication schedule management
- Support for multiple medicines
- Dosage and medication instructions
- Morning, afternoon, and evening schedules
- Medication reminders and voice notifications
- Patient medication response tracking
- Caregiver notifications for missed doses
- Persistent medication schedules
- Support for multiple languages, where configured

## 🛠️ Technologies Used

- Android application development
- HTML, CSS, and JavaScript
- Firebase / SQLite, where configured
- Capacitor for Android integration
- Text-to-Speech for voice reminders

## ⚙️ How It Works

1. The patient or caregiver configures medication details.
2. The app stores the medication schedule.
3. The patient receives a reminder at the scheduled time.
4. The patient records whether the medicine was taken.
5. If the patient does not respond, the configured reminder process can notify the caregiver.

## 🚀 Installation

1. Download the Android APK from the project's Releases section, if published.
2. Install it on a compatible Android device.
3. Grant the required notification permissions.
4. Configure the patient account and medication schedule.
5. Test reminders and caregiver notifications.

## 🔐 Privacy and Safety

- Keep account credentials and API keys private.
- Protect patient and caregiver information.
- Test reminder and notification behavior on supported devices.
- This application is a medication-management aid and does not replace professional medical advice.
